# scoop-bucket

[Scoop](https://scoop.sh) bucket for [sping](https://github.com/LambdaBytes/sping), a terminal-native real-time connectivity monitor.

```powershell
scoop bucket add lambdabytes https://github.com/LambdaBytes/scoop-bucket
scoop install lambdabytes/sping
```

`bucket/sping.json` is written by sping's release workflow when a version is published.
